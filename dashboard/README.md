# セミナー用 AI社員ラボ

3社員の「入力 → 担当・手順 → 成果」を、実ファイルで見せるローカルダッシュボードです。入力原本・社員定義・成果物は変更しません。

## 起動

Python 3.10以降の標準ライブラリだけを使います。依存パッケージの追加、ネット接続、アカウントは不要です。リポジトリのルートで実行します。

```sh
python3 dashboard/serve.py
```

ブラウザで **http://127.0.0.1:8765** を開きます。終了はターミナルで `Ctrl+C`。ポートが使用中なら `python3 dashboard/serve.py --port 8766` として、表示されたURLを開いてください。

HTMLファイルのダブルクリックでは起動しません。ブラウザからローカル資料を読むため、上記のローカルHTTPサーバーを使用します。サーバーは `127.0.0.1` のみに接続し、他のPC向けには公開しません。

## 見せる順番

1. 左の一覧でsales・minutes・reconciliationを選び、「仕事の全体像」で仕事内容とヒアリングの概要を説明します。
2. 「01 入力」でCSVや会議メモの原文を開きます。
3. 「02 担当・手順」でAGENTS.md、SKILL.mdと参照資料を開き、何を任せて、何を任せないかを見せます。Markdownは「整形表示」で開き、見出し・箇条書き・表・コード・引用・リンクを読みやすく表示します。表とコードは横スクロールでき、長い文書は表示枠内で縦スクロールできます。
4. 「03 成果」で保存済みHTMLを操作します。「別タブで開く」で広く表示できます。
5. 「全文ソース」でHTML・JSONも原文のまま確認できます。大きいファイルは最大160行・32,000文字ずつ表示し、全行を検索・ページ切替・ダウンロードできます。同じ行の複数の一致も上下ボタン（Enter / Shift+Enter）で辿り、該当位置を強調表示します。

右上の「投影表示」は文字を大きくします。ブラウザの全画面表示・ズームも併用できます。ヒアリング全文、実行パラメータ、版の台帳は全体像から開けます。画面のURLには社員・表示・選択ファイルが含まれるので、再読込やブラウザの戻る操作でも確認箇所を辿れます。

## 更新元と表示範囲

- 社員の呼称・目的は各 `sample/<社員>/AGENTS.md`、ヒアリング概要は `interview.md` から読みます。概要は原文の抜粋なので、全文で条件を確認してください。
- Skillと参照資料は `.claude/skills/` の実ファイルを列挙します。Codex用の `.agents/skills/` との接続も表示します。別の社員定義をダッシュボード内に作りません。
- inputsを実ファイルから列挙し、最新outputsは `sample.json` の `latest_run.output_sha256` が指定するファイルを表示します。更新後は「再読込」。生成・ビルドは不要です。
- 保存済みの成果物を表示する画面です。業務実行や検収・公開は行いません。現在の定義と、成果作成時の定義のhashはsample.jsonで区別しています。

Markdownは同梱したmarkdown-it 15.0.3で解析し、許可した要素だけをDOMで組み立てます。文書内の生HTMLは文字として表示し、厳密な空の `<a id="…"></a>` だけを見出し移動先として扱います。画像は説明文のみ表示し、自動取得しません。危険なURL・未登録ファイル・社員フォルダ外のリンクは無効化します。相対リンクは実ファイルのディレクトリを基準に解決し、同じ社員の登録済み資料をダッシュボード内で開きます。HTTP(S)リンクはクリック時だけ別タブで開きます。YAML冒頭情報は折りたたみ表示で確認できます。

「全文ソース」で原文へ切り替え、「整形表示」で戻せます。表示モードと資料へのリンクはURLに保持され、ブラウザの戻る・進むが使えます。CSVなどはテキストとして表示します。成果HTMLだけは元のbytesのまま表示し、sandboxとContent Security Policyで親画面操作やfetch・画像等の外部読込を制限します。HTML自身による別ページへの移動まで遮断する仕組みではないため、表示対象はこのキットの保存済み成果に限定しています。将来追加するレポートが外部ライブラリや外部画像を要求すると、その部分は表示されません。ローカルファイルだけで完結する成果を使用してください。

表示対象は3社員の指定ファイルだけです。リポジトリ全体、未追跡のセミナー資料、秘密ファイルを配信する汎用ファイルサーバーではありません。

## 検査

```sh
python3 -B dashboard/test_dashboard.py
# Node.jsがある場合：巨大な1行やUnicode境界のページ分割も検査
node dashboard/test_source_pages.cjs
node --test dashboard/test_markdown_view.cjs
python3 -I -B scripts/verify_samples.py
```

HTTP検査は一時ディレクトリの架空資料で、原文一致、最新成果の選択、更新・欠落、リンクの範囲、外部参照の拒否、書込み不可を確認します。実ブラウザでは3社員の切替、AGENTS/Skill/入力の読込み、成果表示、全文検索・ページ切替、投影表示、狭い画面、開発者コンソールを確認してください。
