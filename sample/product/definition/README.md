# 過去の社員定義を読む（説明用）

このディレクトリの `.sample.md` は、以前の試験で使った定義の参照複製です。本文をコードブロックで囲み、当時のローカルパスを匿名化しています。正式な `AGENTS.md` / `CLAUDE.md` / `SKILL.md` として自動読込みされる配置ではありません。ファイル名だけを変えて使うと、依存資料や参照先が揃いません。

[この試験の説明](../README.md)へ戻ると、実行用サンプルへの案内を確認できます。

商品紹介の実行用workspaceは未配布です。[キットの聞き取り・生成手順](../../../README.md#はじめ方)から作成してください。
