# 正式なworkspaceの生成・認識・再実行の検証

2026-10-16に、仕様0.1.4-draft／Q&A 0.1.2-draftのキットから3社員をそれぞれ新規生成しました。AGENTS・Skill・入力を揃えた配布束をキット外へコピーし、別の新しいCodex会話で入力から業務成果物を生成しています。全て架空資料・AI模擬回答による試験で、人の定義承認・成果検収ではありません。

**新しく生成した正式なサンプル成果物は [sample/results](../results/README.md) にあります。** この検証ディレクトリだけに成果物を置いているわけではありません。旧 `sample/sales`・`sample/minutes`・`sample/product` は以前の別試験を読む資料として保持し、そこからも最新結果へ案内しています。

[試験の集約記録](trial-summary.json)。認識確認はCodex CLI 0.159.2/app-serverで実施しました。初期コンテキスト確認では手動のファイル表示を行わせず、各業務は新規会話で明示Skillを読み込んでいます。独立担当は事前期待値と全入力行・引用・集計・割当・候補を照合しました。照合数はこの固定資料上の検査件数で、一般的な業務精度ではありません。

[構造検査126件](structure/validator-regressions.json)、[コピー検査23件](structure/copy-helper-regressions.json) が合格しました。大小文字、4つの実ディレクトリ、絶対・切断・外部symlink、説明用フェンス、K/W分離、文書リンクの対応範囲、`.DS_Store`、コピー先の重なりを点検しています。公開用にパスを記号化した束も構造・コピー・ハッシュの検査に合格しました。

生成時に使ったAGENTS本文・Skill本文・入力原本を保持しています。公開時にローカルパスを記号化した記録・レポートは、原本と公開複製のSHAを各結果のrun-manifest.jsonと [公開変換記録](public-export.json) で分けています。生成時の未検証欄や、実行記録の原本ハッシュを後から成功や公開複製の値へ書き換えていません。正解となる過去出力を新しい業務担当へ渡していません。

最初の起動ラッパーは依頼文準備のエラーでCodexを開始できず、v002の起動が最初の業務実行です。独立検証器の初期版では入れ子構造・引用末尾改行・動的HTML表示の解釈を修正しました。社員の業務出力や期待値は修正せず照合が合格しています。これらを初回から無失敗だったとは扱いません。

新規3レポートはユーザーのMacのOrcaブラウザで先頭表示を確認済みです。公開複製の3レポートも実際に開き、表示を確認しました。Codex DesktopのSkill選択UI、Claude Codeでの社員業務、全操作・モバイル・印刷、Excelファイル、実顧客データ、人による検収は未検証です。静的なMarkdown検査は [明記した部分集合](../../docs/compatibility.md) であり、OS権限や全依存の網羅を保証しません。

[公開版の最終確認](publication-verification.json)に、旧サンプルからの導線、再生成物との対応、表示確認、個人のローカルパス等を除いたことを記録しています。
