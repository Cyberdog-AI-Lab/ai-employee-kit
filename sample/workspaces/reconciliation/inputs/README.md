# 架空の請求・入金資料

会社: こもれび業務支援（架空）。dataset_id: AR-DEMO-2026。請求100件、取引先20件、銀行入金90行を収録。基準日は実行依頼で指定する。これはAI社員のローカル試験資料であり、実在の取引・口座・担当者・契約ではない。

- invoices.csv: 税込の請求額、発行日、支払期日。金額は正の整数JPY。
- bank-credits.csv: 振込時メッセージ欄も取得できた架空の入金エクスポート。すべての実銀行形式でこの情報を取得できるとは想定しない。銀行の入金のみ。出金や口座残高は含まない。基準日後の入金が含まれるため対象判定が必要。
- customers.csv: 取引先ID、名称、承認済み振込名義2種、明示された手数料契約。未登録名義は追加せず要確認。
- matching-rules.md: この試験で合意した照合・保留・検算規則。実際の会計方針の推奨ではない。

原本保持。全結果は人の確認前。実行パラメータ不足を本書から補って開始しない。
