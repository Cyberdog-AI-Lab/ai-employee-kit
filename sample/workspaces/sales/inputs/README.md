# こもれび商店・架空の売上資料

全資料はAIが作成した架空の試験用データ。実在店舗の業績ではない。
期間は2026年7〜9月、4店舗、24商品。店舗ごとの出力では同じ店舗・商品の表記が揺れている。マスタにある対応だけが確定した対応表である。
売上金額はquantity × unit_price_jpy − discount_jpy。価格マスタは比較用の基準であり、販売時の記録値を勝手に訂正する根拠ではない。割引は行全体の税込円で、税の再計算はしない。
返品は返品日ベースの実返金額。元の売上IDで店舗・商品へ結びつける。行はすべて原本として保持する。
重複、数量空欄、未登録名、照合できない返品を含む。採用・保留方針は社員のヒアリングで定義する。

返金額は返品伝票に記録された実際の返金額であり、計算上の按分額ではない。値引き配賦を逆算して返金額を訂正しない。R001〜R068は販売日の2日後という架空設定で、月をまたぐ返品を含む。R069〜R071は元売上の照合が必要な伝票、R072はそれとは別の返品伝票である。
店舗メモの出来事は数値変化と併記できるが、因果関係が立証されたことを意味しない。
